### 踩过的坑

- **parquet 里的类别名格式与预期不符**：一开始按 `{"class_label": {"names": ...}}` 解析，
  实际是 `{"names": [...], "_type": "ClassLabel"}`，直接 KeyError。
  改成兼容三种历史格式。教训：不要凭印象写解析代码，先把 metadata 打印出来看。
- **Windows 下目录 rename 失败**：`staging.rename(out_dir / "train")` 在目标目录已存在时抛
  `WinError 183`，导致脚本不能重复执行。改成逐类别目录移动。
- **中文输出乱码**：PowerShell 默认不是 UTF-8，Python 打印中文变问号。需设 `$env:PYTHONIOENCODING='utf-8'`。

## 2026-11-20 ~ 11-21

### 完成

1. **数据集体检**（`ml/src/data_audit.py` → `ml/artifacts/data_audit.md`）
   - 实测类别不均衡：最多类 `15_Orange_Haunglongbing_Citrus_greening` 3966 张，
     最少类 `22_Potato_healthy` 110 张，极差 36.1 倍，多数类占比 10.1%。
     （此前记录里把这两个类说反了，以本次实测为准。）
   - 抽样 400 张全部 RGB / 256×256。抽样网格显示背景高度一致（单一浅色背景、居中单片叶），
     这是 PlantVillage「实验室摆拍」的直接证据，也是后面跨域实验的立论基础。

2. **手写特征基线**（`ml/src/handcrafted_baseline.py`）
   - 动机：iWSP 论文（arXiv:2611.18114）用大模型手写视觉特征打败经典可解释基线的思路。
   - 162 维手工特征：HSV 颜色直方图 102 维 + GLCM 纹理 12 维 + Gabor 48 维，接 LogisticRegression。
   - **结果：test acc 92.17%，macro-F1 90.43%**；特征提取 1557 s，分类器训练仅 7.7 s。
   - 意义：162 个手工数字、7.7 秒训练就到 92%，说明 PlantVillage 这个任务本身不难。
     文献里各网络都报 99%，更多是任务简单而非模型强。**在 PlantVillage 上比精度没有意义**，
     这条判断决定了整个项目的实验设计（重心放在跨域与效率，不是刷榜）。

3. **CPU 吞吐实测**（`ml/src/bench_cpu.py`）
   - 纯前向反向：resnet18 24.4 img/s、mobilenet_v3_large 31.2 img/s。
   - **真实训练实测（含数据加载与强增强）：7.1 img/s**，单轮 92 分钟，15 轮约 23 小时。
   - 结论：本机 CPU 训练不可行，正式训练必须上 Colab。

4. **Colab 训练管线**（`ml/src/train_colab.py` + `scripts/colab_launch.py` + `scripts/colab_fetch.py`）
   - 用 Google 官方 Colab CLI（`google-colab-cli` 0.8.0）从终端开 T4 会话，不依赖浏览器。
   - `train_colab.py` 自包含（数据下载/转换/训练/评估/ONNX 导出一体），因为 `colab exec -f`
     只送单个文件，本地 import 不跟随。
   - `colab_launch.py` 用 nohup 分离进程 + 日志文件跑训练，解决 `colab exec` 长连接一断就丢输出。

5. **ResNet18 全量训练（进行中）**
   - 配置：224px / batch 64 / 15 轮 / 强增强 / 分层学习率 / 标签平滑 0.1。
   - 数据：train 39153 / val 4350 / test 10878，38 类。
   - T4 吞吐实测 116.8 img/s，单轮约 5.8 分钟。
   - 已完成轮次：epoch 1 val_acc 91.20%，epoch 2 val_acc **97.45%**（macro-F1 0.964）。

6. **安卓端与后端**（Alpha 演示链路，已跑通）
   - `server/`：FastAPI + SQLite，三种推理后端（ONNX / Torch / 假模型）自动降级。
   - `app/`：Kotlin + Compose 单 Activity，系统相机 Intent + FileProvider，
     `HttpURLConnection` 手写 multipart（Gradle 缓存里没有 Retrofit/OkHttp）。
   - 模拟器实测：拍照/选图 → 上传 → 显示 top-3 结果与耗时 → 反馈按钮，全链路通。

### 踩过的坑

- **Colab CLI 授权缺 scope**：第一次授权时 Google 只返回 3 个权限（profile/email/openid），
  缺 `colaboratory`/`cloud-platform`/`drive.file`，oauthlib 抛 `Scope has changed`，token 没写进 keyring。
  解法：`OAUTHLIB_RELAX_TOKEN_SCOPE=1` 先存 token，且授权页必须把所有复选框勾上。
  另：授权码一次性、约 10 分钟过期，复用旧码报 `invalid_grant`。
- **`Get-Process python | Stop-Process` 误杀了正在跑的 Colab 训练**：远端 kernel 还在算，
  但本地输出流断了，拿不到结果。教训：重启本地服务必须按端口杀进程
  （`Get-NetTCPConnection -LocalPort 8000`），绝不按进程名批量杀。
- **`colab exec` 读文件用 GBK 解码**：PowerShell 管道下报 `UnicodeDecodeError`，需设 `$env:PYTHONUTF8='1'`。
- **`datasets` 4.8.5 的 `row["image"]` 是已解码的 PIL Image**，不是 `{"bytes": ...}` 字典，
  按字典取会 `TypeError: 'JpegImageFile' object is not subscriptable`。
- **AGP 拒绝含中文的项目路径**：`Your project path contains non-ASCII characters`。
  解法：`app/gradle.properties` 加 `android.overridePathCheck=true`。
- **`cv2.imread` 读不了中文路径**（Windows），必须 `np.fromfile` + `cv2.imdecode`。
