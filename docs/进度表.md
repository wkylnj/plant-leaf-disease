## 2026-11-17

### 完成

1. **环境勘察**
   - 本机无 NVIDIA GPU（AMD Radeon 780M 核显），确认只能 CPU 本地调试、Colab 正式训练。
   - 修好了 `C:\android-sdk` 的 `JAVA_HOME` 指向错误（`jdk-17.0.20.1-hotspot` → 实际目录 `jdk-17.0.20.101-hotspot`），
     安卓模拟器 `focus_test`（Pixel 6 / Android 15）已能启动，`adb devices` 可见。
     这一步的意义：App 后续可以真的编译安装截图验证，不是交一份没跑过的代码。

2. **数据集获取**
   - 源：HuggingFace `GVJahnavi/PlantVillage_dataset`，3 个 parquet 共 852 MB。
   - 下到 `ml/data/raw/plantvillage/`。

3. **数据预处理管线**（`ml/src/prepare_data.py`）
   - parquet → ImageFolder（jpg），并做分层切分。
   - 结果：train 39170 / val 4333 / test 10878，共 54381 张，38 类。
   - 类别不均衡情况：最少类 122 张，最多类 4406 张，相差 36 倍。

4. **数据加载模块**（`ml/src/data.py`）
   - 统一 transform，区分强弱增强，供后续消融实验复用。
   - 支持 WeightedRandomSampler 做类别平衡采样。

### 踩过的坑

- **parquet 里的类别名格式与预期不符**：一开始按 `{"class_label": {"names": ...}}` 解析，
  实际是 `{"names": [...], "_type": "ClassLabel"}`，直接 KeyError。
  改成兼容三种历史格式。教训：不要凭印象写解析代码，先把 metadata 打印出来看。
- **Windows 下目录 rename 失败**：`staging.rename(out_dir / "train")` 在目标目录已存在时抛
  `WinError 183`，导致脚本不能重复执行。改成逐类别目录移动。
- **中文输出乱码**：PowerShell 默认不是 UTF-8，Python 打印中文变问号。需设 `$env:PYTHONIOENCODING='utf-8'`。
