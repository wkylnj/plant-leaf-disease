## 一、三个人见面，拍一张合照

## 二、每人 clone 仓库，配 git 身份

**为什么**：作业要求「展示当日代码/文档签入记录」。三个人各有一条今天的提交，比一个人十条更有说服力。

**步骤**（逐条复制粘贴）：

```bash
# 1. 克隆
git clone https://github.com/wkylnj/plant-leaf-disease.git
cd plant-leaf-disease

# 2. 配置身份（把名字和邮箱换成你自己的）
git config user.name "你的名字"
git config user.email "你的邮箱"

# 3. 切到 dev 分支
git checkout dev
```

**没有 GitHub 账号的**：先去 https://github.com/signup 注册，然后把用户名发给组长，让组长拉你进仓库。

## 附：常见问题

**Q: 我没有装 Python**
去 https://www.python.org/downloads/ 下 3.12，安装时**勾选 Add Python to PATH**。

**Q: `python` 命令找不到**
Windows 上试 `py` 或 `python3`。

**Q: git 提示 `fatal: not a git repository`**
说明没在仓库目录里，先 `cd plant-leaf-disease`。

**Q: push 要输密码**
GitHub 已不支持密码推送，需要用 Personal Access Token。让组长帮你配 SSH 密钥，或者用 GitHub Desktop 图形客户端。

**Q: 完全不想碰命令行**
可以，用 [GitHub Desktop](https://desktop.github.com/)，图形化操作。但**至少要会用命令行 clone 和 commit**，否则后面部署服务器会很痛苦。
