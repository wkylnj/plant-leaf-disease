# E-15 跨域预处理消融

- 模型：`resnet18_224_15ep`（resnet18）
- 样本：PlantDoc `all` 划分，2920 张
- 口径：模型权重不动，只换「图怎么喂进去」

| 喂法 | 说明 | top-1 | top-3 | 作物级 | 平均置信度 | 耗时(s) |
|---|---|---|---|---|---|---|
| `baseline` | 短边256→中心裁224（历史口径） | 0.2818 | 0.4901 | 0.5113 | 0.4366 | 257.2 |
| `center256` |  | 0.2969 | 0.4973 | 0.5271 | 0.3887 | 304.5 |
| `center288` |  | 0.3021 | 0.4993 | 0.5370 | 0.3496 | 325.8 |
| `center320` | 短边356→中心裁320，224转320前向 | 0.3038 | 0.4990 | 0.5435 | 0.3236 | 212.4 |

## 结论

### 1. 唯一有效的是「提高推理分辨率」

全量 2920 张上单调递增，不重训即得 **+2.20pp（top-1）/ +3.22pp（作物级）**：

| 分辨率 | top-1 | 作物级 |
|---|---|---|
| 224（历史口径） | 0.2818 | 0.5113 |
| 256 | 0.2969 | 0.5271 |
| 288 | 0.3021 | 0.5370 |
| 320 | **0.3038** | **0.5435** |

### 2. 所有「改形状」的喂法都是负收益

`squash`（整图拉伸到 224）0.2937、`short224`（直接缩到短边 224）0.2976、`letterbox`（等比+填边）0.2579、`multiscale`（3 种喂法 × 翻转共 6 视图平均）0.3214（test 252 张口径，基线 0.3373）。

机制解释：PlantDoc 的叶片在画面中占比、长宽比与 PlantVillage 差异很大，强行改成 PlantVillage 的构图会把叶片细节压掉；而**放大**不改变构图、只增加像素密度，让病斑纹理真正进入模型的感受野。

### 3. 为什么 320 有效、384/448 又变差

test 252 张上扫描：256 → 0.3611、288 → **0.3730**、320 → 0.3532、384 → 0.3373、448 → 0.3135。峰值在 256~288，之后下降。

原因：模型是在 224 上训练的，感受野与纹理尺度都按 224 标定。分辨率继续加大时，叶片上的病斑相对模型的感受野变小、有效纹理被拉散，判决反而变差。即**「训练分辨率的 1.3~1.4 倍」是安全区**。

### 4. 对后续实验的约束

- `local_crop`（局部裁剪训练）与 `bg_replace`（背景替换）这两个训练侧实验，**评估必须用 PlantDoc 跨域**，同域 val 精度下降是预期内的，不能用 `summary.json` 的 test_acc 判断成败。
- 分辨率增益与集成增益是正交的（一个改输入尺度、一个改模型多样性），可以叠加，正在合并验证。
