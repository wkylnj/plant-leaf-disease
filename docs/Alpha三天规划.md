## 1. 目标降级：Alpha 阶段砍掉什么

Alpha 是「初步可运行软件」，不是成品。按你一个人的产能，必须砍。

### 保留（Alpha 必须有）

1. **训练跑通** —— 至少一个 CNN 模型有真实的 test accuracy
2. **一个能跑的东西** —— 哪怕只是命令行 `predict.py`，输入图片路径输出类别
3. **完整报告** —— 五个部分齐全，反思诚实

### 砍到 Beta

| 砍掉的 | 理由 |
|---|---|
| 后端 FastAPI + 数据库 | 需要第二个人，一个人做不完 |
| 安卓 App | 零基础一个人做不完，且需要后端才能联调 |
| 六模型全跑 | 先跑 ResNet18 + MobileNetV3 两个就够对比 |
| 跨域实验 PlantDoc | 属于 Beta 的深度工作 |
| Grad-CAM | 同上 |

### 砍掉之后报告怎么写

在「还剩下哪些任务」里如实列出，并说明为什么延期——**这不是扣分项，是计划能力的体现**。课程要的是「初步可运行」，不是「全部完成」。

## 2. 训练方案：三条路，推荐第三条

本地实测：**7.1 img/s**（224px + 强增强 + 4 workers），一轮 92 分钟，15 轮 23 小时。不可行。

### 方案 A：本地降配过夜跑

| 参数 | 值 |
|---|---|
| 分辨率 | 160px |
| epoch | 8 |
| 增强 | 弱（`--weak-aug`） |
| 预计速度 | 18–25 img/s |
| 预计耗时 | **4–5 小时** |
| 预期精度 | 92%–96%（不确定，160px 会掉点） |

**优点**：今晚就能启动，明早起床有结果，完全不依赖网络。
**缺点**：精度不如完整配置，报告里要如实标注「Alpha 阶段使用降配配置，完整训练在 Beta 补」。

### 方案 B：Colab 免费 T4

| 参数 | 值 |
|---|---|
| 分辨率 | 224px |
| epoch | 15 |
| 增强 | 强 |
| 预计耗时 | **25 分钟** |
| 预期精度 | 97%–99% |

**优点**：快、精度高、能顺手跑两三个模型做对比。
**缺点**：需要 Google 账号；Colab 免费版可能限速或断连；国内网络可能需要代理。

### 方案 C：两个都做（推荐）

1. **今晚先启动本地降配训练**，作为保底 —— 万一 Colab 用不了，明早也有结果
2. **明天上午试 Colab**，成功就用它的结果作为报告主数据，本地那个降级为「算力对比实验」的素材
3. 两个结果都留着 —— 160px vs 224px、8 epoch vs 15 epoch 的差异，本身就是一张有价值的对照表

**为什么推荐 C**：你现在的风险不是「精度不够高」，而是「一个 CNN 结果都没有」。先保证有，再追求好。

## 附：本地降配训练的具体命令

```bash
cd ml
python src/train.py \
  --model resnet18 \
  --data-root data/processed/plantvillage \
  --img-size 160 \
  --epochs 8 \
  --batch-size 32 \
  --num-workers 4 \
  --weak-aug \
  --out-dir ../runs \
  --run-name resnet18_160px_e8
```

预计 4–5 小时。跑完后 `runs/resnet18_160px_e8/summary.json` 里有 `test_acc` 和 `test_macro_f1`。
