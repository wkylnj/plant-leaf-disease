# 手写特征基线（E0）

> 目的：量化「ImageNet 预训练的 1100 万个参数，到底比人手设计的特征强多少」。
> 脚本：`ml/src/handcrafted_baseline.py`
> 产出：`ml/artifacts/handcrafted_full_summary.json`、`handcrafted_full_report.txt`

## 1. 为什么做这个实验

报告里绕不开一个问题：**我们用 ImageNet 预训练权重微调，是不是在「调包」？**

如果只报一个「ResNet18 微调达到 98.5%」，这个数字是没有参照的——读者无法判断这 98.5% 里有多少来自深度学习、有多少来自任务本身简单。

所以先建立一个**完全不使用神经网络**的基线：用人工设计的特征 + 一个线性分类器。这个基线不需要预训练权重、不需要反向传播、不需要 GPU。它的数字就是「不用深度学习能做到什么程度」的下界。

## 2. 方法

### 2.1 特征设计

共 162 维，分三组：

| 特征组 | 维度 | 具体内容 | 为什么选它 |
|---|---:|---|---|
| 颜色 | 102 | HSV 三通道各 32 bin 直方图（归一化为分布）+ 每通道均值/标准差 | 病斑最直接的表现是变色（黄化、褐变、黑腐），颜色分布是这类任务最强的单一线索 |
| GLCM 纹理 | 12 | 灰度共生矩阵的对比度、相异性、同质性、能量、相关性、ASM，取 4 方向 × 2 距离的均值与标准差 | 病斑区域质地粗糙，与健康组织的平滑表面在纹理统计上不同 |
| Gabor | 48 | 4 个尺度 × 6 个方向的 Gabor 核响应，每核取均值与标准差 | 病斑边缘与叶脉有方向性，Gabor 是描述方向性纹理的经典工具 |

实现细节：

- 灰度量化到 16 级后再算 GLCM。级数越少共生矩阵越稠密，对光照变化越鲁棒。
- Gabor 核做了去直流处理（`kern -= kern.mean()`），避免响应被整体亮度主导。
- 颜色直方图做了 L1 归一化，消除叶片大小和拍摄距离的影响。
- 图像统一缩放到 224×224（与后续 CNN 输入一致），使用 `INTER_AREA` 插值避免摩尔纹。

### 2.2 分类器

`StandardScaler` + `LogisticRegression(C=1.0, class_weight="balanced", max_iter=2000)`。

用 `class_weight="balanced"` 是因为类别相差 36 倍，不加权的话模型会倾向于多数类。

## 4. 分析：这个结果说明了什么

### 4.1 92% 意味着这个任务本身不难

162 个手工设计的数字，训练 7.7 秒，就能在 38 类上达到 92%。这说明 PlantVillage 的判别信息**大量存在于低层视觉统计量中**——颜色、纹理、方向性边缘。

这也解释了为什么文献里 ResNet、VGG、Inception 在这份数据集上全都能报到 99%：任务太简单，模型容量的差异被数据集的简单性掩盖了。**这恰好是我们项目要论证的核心观点之一——在 PlantVillage 上比精度是没有意义的。**

### 4.2 剩下 8% 的差距在哪里

看最难识别的类别，全是马铃薯和番茄。共同点：

- **Potato healthy vs Potato Late blight**：两者都是绿色叶片，病斑只在局部，且早期病斑很小。颜色直方图统计的是全图分布，局部小斑点在全局统计里被稀释。
- **Tomato Early blight vs Tomato Late blight**：两种病的症状都是褐色斑点，但斑点的**形状和分布模式**不同——早疫病是同心轮纹，晚疫病是不规则水渍状。这种空间结构的差异，全局统计量抓不住。

**这正是卷积神经网络的价值所在**：卷积核在局部窗口上滑动，能捕捉「这个位置有一个不规则褐色区域」这类空间模式，而直方图只能回答「全图有多少褐色像素」。

所以后面 ResNet18 微调如果能到 98%，那 6 个百分点的提升，来源可以明确归因为**空间结构建模能力**，而不是「深度学习比较玄」。

### 4.3 与 iWSP 论文的关系

这个实验的设计受 arXiv:2611.18114（iWSP）的视觉皮层实验启发。该文用 14 个显式计算产出约 1 万维特征配合 ridge regression，在神经科学基准上打败全部经典可解释基线，但**仍略低于黑箱 AlexNet**。

我们的结果呈现同样的模式：手写特征很强（92%），但预期仍会低于端到端训练的 CNN。差别在于我们的任务比论文的神经预测任务简单得多，所以手写特征能走得更远。

## 5. 复现方式

```bash
# 全量（约 26 分钟，CPU）
python ml/src/handcrafted_baseline.py

# 快速验证（每类 20 张，约 50 秒）
python ml/src/handcrafted_baseline.py --limit-per-class 20 --out-name smoke_handcrafted

# 只用部分特征组，看各组贡献
python ml/src/handcrafted_baseline.py --features color
python ml/src/handcrafted_baseline.py --features color,glcm
```

## 6. 待补充的消融

以下实验可以在 Beta 阶段补做，用于回答「哪组特征贡献最大」：

| 实验 | 目的 |
|---|---|
| 只用 color | 颜色单独能到多少 |
| 只用 glcm | 纹理单独能到多少 |
| 只用 gabor | 方向性单独能到多少 |
| color + glcm | 两组是否互补 |
| 全部三组（已完成） | 92.17% |

预期：颜色组单独就能到 85% 以上，纹理与 Gabor 主要贡献在难分类别上。若成立，可进一步论证「这个数据集的判别信息主要在颜色上」。
