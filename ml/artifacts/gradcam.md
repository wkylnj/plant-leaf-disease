# E7 Grad-CAM：模型到底在看病斑还是背景？

> 实验日期：2026-11-21
> 模型：ResNet18（`ml/runs/resnet18_224_15ep/best.pt`，test_acc 99.41%）
> 样本：38 类 × 2 张 = 76 张测试图
> 复现：`python src/gradcam.py --run-dir runs/resnet18_224_15ep --per-class 2 --num 76`

---

## 1. 这个实验要验证什么

原方案里预写的第 4 条结论是：

> **模型看的是背景而不是病斑，这解释了为什么跨域会崩。**

这个假设来自一个合理的推理链：

1. PlantVillage 是实验室摆拍数据集——背景统一浅色、叶片居中、光照一致、单片叶子
2. 模型在测试集上能到 99%
3. 如果模型学的是"背景 + 叶片整体轮廓"这条捷径，那么在真实田间照片上就会崩
4. Grad-CAM 热力图应该亮在叶片之外（背景区域）

**实验结果是：第 1–3 步成立，但第 4 步不成立。**

模型没有看背景。但它也没有看病斑。它看的是"整片叶子的全局统计特征"。

## 2. 量化指标

### 2.1 注意力空间分布

| 指标 | 数值 | 解读 |
|---|---|---|
| 中心 50% 区域注意力占比 | **47.5%** | 注意力集中在叶片主体 |
| 四角（各 25%×25%）注意力占比 | **2.7%** | 几乎不看背景 |
| 抽样准确率 | 98.68%（75/76） | 与全量 99.41% 一致 |

**四角注意力仅 2.7%** 是决定性证据。如果模型靠背景作弊，这个数字应该在 20% 以上。

### 2.2 九宫格网格分布

```
        左列    中列    右列
上排    14.1%   13.4%    7.9%
中排    15.7%   14.6%    8.4%
下排    10.2%    9.8%    5.9%
```

边际分布：

| 方向 | 占比 |
|---|---|
| 左列 | 39.9% |
| 中列 | 37.9% |
| 右列 | 22.2% |
| 上排 | 35.4% |
| 中排 | 38.8% |
| 下排 | 25.9% |

**注意力明显偏左上**（左列 39.9% vs 右列 22.2%）。这不是均匀分布，说明模型有固定的空间偏好——很可能是因为 PlantVillage 的叶片在拍摄时普遍偏左、叶柄朝右下。

### 2.3 健康叶 vs 病叶的注意力模式

| 分组 | 样本数 | 中心注意力 | 四角注意力 | 平均置信度 |
|---|---|---|---|---|
| 健康类 | 24 | 46.9% | 2.7% | 88.6% |
| 病害类 | 52 | 47.7% | 2.6% | 87.3% |

**两者几乎完全相同。** 这是本实验最重要的发现：模型对"健康叶"和"病叶"的观察方式没有区别。如果它真的在找病斑，健康叶的注意力应该更分散或落在叶脉上，病叶的注意力应该集中在斑点处。

### 2.4 注意力集中度与置信度

| 分组 | 样本数 | 平均置信度 |
|---|---|---|
| 注意力集中（单格 > 20%） | 23 | 85.4% |
| 注意力分散（单格 ≤ 20%） | 53 | **88.7%** |

**注意力越分散，模型反而越自信。** 这与"模型在找局部病斑"的预期相反——找局部特征时，注意力越集中应该越自信。分散且自信，说明它依赖的是遍布全图的统计量。

## 4. 结论：假设被推翻，但机制更清楚了

### 4.1 被推翻的部分

原假设「模型看背景」**不成立**。四角注意力仅 2.7%，模型确实在看叶片。

### 4.2 新发现

**模型学的是"整片叶子的全局统计特征"，不是"病斑的局部形态"。**

证据链：

1. 注意力是弥散的大色块，不是病斑位置的小区域
2. 健康叶与病叶的注意力分布几乎相同（46.9% vs 47.7%）
3. 注意力越分散，置信度反而越高（88.7% vs 85.4%）
4. 有固定空间偏好（偏左上），与拍摄构图相关而非病理特征

### 4.3 为什么这仍然能解释跨域失效

全局统计特征（整体色调、纹理能量、明暗分布）对成像条件高度敏感：

- **光照**：田间强光/阴影会改变整图亮度分布
- **色温**：晴天/阴天/手机白平衡差异会改变色调
- **背景**：泥土、多叶、天空会稀释全局统计量
- **构图**：叶片大小、角度、遮挡会改变空间分布

模型在 PlantVillage 上 99%，是因为训练集和测试集的成像条件完全一致。换到真实照片，这些统计量全部漂移，模型就失效了。

**结论比原假设更有价值**：不是"模型作弊看背景"，而是"模型用了一种对成像条件敏感的表示方式"。前者是数据问题，后者是表示问题——后者更难修，也更值得写。

## 5. 对项目的影响

### 5.1 报告怎么写

这一节应该写成**假设被推翻**的叙事，而不是"验证了我们的猜想"。理由：

- 课程报告里"我们以为 X，实验发现不是 X，而是 Y"比"我们猜对了"可信得多
- 它展示了真实的科学过程：提出假设 → 设计实验 → 数据否定假设 → 修正理解
- 它也解释了为什么我们没有做"换个数据集重训"这种表面工作

### 5.2 跨域实验（E2）的预期

如果模型依赖全局统计特征，那么 PlantDoc 跨域测试的精度崩溃是**必然的**，不是偶然。E2 的实验结果会从另一个角度印证本实验的结论：

- E7（Grad-CAM）说：模型注意力是全局弥散的
- E2（跨域）说：换成像条件后精度崩溃
- 两条独立证据指向同一个机制

### 5.3 后续可做的改进方向（Beta 阶段）

如果要真正提升跨域鲁棒性，方向不是"换更大的模型"，而是：

1. **强色彩/光照增强**：在训练时随机改变色温、亮度、对比度，逼模型忽略全局色调
2. **背景替换**：把叶片抠出来贴到随机背景上（需要分割，成本高）
3. **局部区域裁剪训练**：随机裁剪病斑区域，逼模型关注局部
4. **注意力约束**：显式监督 CAM 落在病斑标注上（需要 bbox，PlantDoc 有）

这些都不在 Alpha 范围内，但可以写进报告的"未来工作"。

## 6. 方法说明（可复现）

### 6.1 Grad-CAM 算法

标准实现（Selvaraju et al., 2017）：

1. 前向传播到目标层（ResNet18 的 `layer4[-1]`），保存激活 `A ∈ R^{C×H×W}`
2. 反向传播预测类别的梯度，保存 `∂y^c/∂A`
3. 通道权重 `α_k = (1/Z) Σ_{i,j} ∂y^c/∂A_{ij}^k`（全局平均池化）
4. 加权求和 `L = ReLU(Σ_k α_k A^k)`
5. 归一化到 [0,1] 并上采样到输入尺寸

### 6.2 量化指标定义

- **中心注意力**：CAM 在图像中心 50%×50% 区域的能量占比
- **四角注意力**：CAM 在四个角各 25%×25% 区域的能量占比之和
- **九宫格质量分布**：把 CAM 按 3×3 切块，每格能量占总能量的比例

### 6.3 为什么用 ResNet18 而不是 MobileNetV3

ResNet18 有完整的 15 轮训练记录和 `history.csv`，指标可信。MobileNetV3 是中断后补测的（第 9 轮权重），用它做可视化会引入额外的不确定性。等 MobileNetV3 完整训练完成后可以再补一组对照，看轻量模型的注意力是否更集中（预期：不会，因为瓶颈不在容量）。

## 7. 已知局限

1. **只测了 ResNet18**。MobileNetV3 与 Swin-T 的注意力模式未测。
2. **样本量 76 张**，每类 2 张，不能代表类内多样性。
3. **没有病斑标注**，无法定量计算"注意力落在病斑上的比例"。要做得更严谨，需要 PlantDoc 的 bbox 标注做 IoU 评估。
4. **Grad-CAM 本身是粗糙的**：它反映的是"梯度最大的区域"，不等于"模型决策的唯一依据"。用不同目标层会得到不同结果。
5. **没有做遮挡实验对照**。更严格的验证是遮挡病斑看精度掉多少（Occlusion Sensitivity），但计算成本高（每张图要跑几十次前向）。
