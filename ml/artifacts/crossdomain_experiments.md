# 跨域提升实验总览（Beta 第二轮）

## 一句话结论

截至本轮，**提高推理分辨率**是唯一稳定有效且零成本的手段（Swin-T 34.93% → 37.09%）；**测试时适配、颜色对齐、叶片定位裁剪、域适应增强、多模型集成**五条路线全部被实验证伪。真正的瓶颈不是「图怎么喂」，而是模型学到的表示本身。

## 当前最佳配置

**Swin-T @352 分辨率，跨域 top-1 = 37.09%，作物级 57.77%**，零重训成本。这是目前所有实验里的最高成绩，比原始基线（Swin-T @224 = 34.93%）高 2.16pp，比 ResNet18 @224（28.18%）高 8.91pp。

## 被证伪的四条路线

### 1. 域适应数据增强（E-10，`ml/artifacts/beta_model_update.md`）

训练时加 ColorJitter(0.6)、灰度、模糊、自动对比度、均衡，模拟田间光照。

结果：同域 −0.39pp、跨域 −2.22pp、作物级 −2.05pp，**三项全降**。

机制：这些扰动只改变像素统计分布，模型学会忽略扰动后仍稳定的统计量——但那些统计量还是同源数据的统计量。**没改变模型依赖的特征类型**。

### 2. 无标签测试时适配（E-14，`ml/artifacts/tta_adapt.md`）

BN 统计重估、TENT（熵最小化）、伪标签自训练，共 10 组配置。

结果：**10 组全部低于零样本基线**。BN 重估稳定掉 6pp；TENT lr=1e-3 崩塌成退化解（置信度 0.9993、准确率 3.17%，低于随机）；lr=1e-4 不崩但仍 −3~4pp；伪标签因目标域置信度太低只保留 11~14% 样本。

机制：跨域掉点主要是**特征本身不对**，不是统计量漂移或决策边界不尖锐。无标签 TTA 修不动。

### 3. 推理时颜色对齐（E-17，`ml/runs/resnet18_224_15ep/color_align.json`）

在 CIELAB 空间把 PlantDoc 图像的颜色统计量向 PlantVillage 对齐（Reinhard 色彩迁移），强度 alpha 扫描。

结果（test 252 张，ResNet18）：alpha=0 → 0.3413（基线）、0.3 → 0.3254、0.6 → 0.3294、1.0 → 0.3135。**单调下降**。

机制：颜色对齐只统一了「整体色调」，但模型依赖的是颜色与纹理的**联合分布**，单改颜色均值/方差反而破坏了叶片本身的色彩语义（健康绿 vs 病斑黄褐的判别信息被抹平）。

### 4. 叶片定位裁剪（E-16，`ml/runs/resnet18_224_15ep/leafcrop.json`）

用超绿指数 + Otsu 阈值 + 形态学 + 最大连通域定位叶片包围盒，裁剪后放大到 224。

结果（test 252 张）：基线 0.3373 → `leafcrop` 0.3016（−3.57pp）、`leafcrop_wide`（放大 1.4 倍）0.3095（−2.78pp）。抠图成功率 100%（0 张回退）。

机制：**尺度错位不是主因**。裁剪后模型失去了它依赖的「整片叶子的全局构图」，反而更差——模型从没见过「叶片占满画面」的输入。

## 有效的两条路线

### 1. 提高推理分辨率（E-15）

见 `ml/artifacts/preprocess_ablation.md`。零成本、不改权重，Swin-T +2.16pp、ResNet18 +2.20pp。安全区是训练分辨率的 1.3~1.6 倍，超过后反而下降。

### 2. 多模型集成（E-11）——**在强模型存在时不成立**

| 配置 | top-1 | 作物级 | 结论 |
|---|---|---|---|
| 双模型（ResNet18+MobileNetV3）@224 + TTA | 0.2911 | 0.5473 | 比单模型 +0.93pp，有效 |
| 三模型 @最优分辨率等权 | 0.3449 | 0.5904 | **低于 Swin-T 单独 0.3709** |
| 三模型加权（全量搜索最优 0.9/0.3/0.1） | 0.3712 | 0.5856 | 仅 +0.03pp，噪声水平 |
| 三模型加权（5 折 CV 泛化估计） | 0.3630 | — | **低于 Swin-T 单独 0.3709** |

关键发现：**当成员能力差距大时，集成会拖累强模型**。全量搜索到的「最优」权重（+0.03pp）在交叉验证下消失（−0.79pp），说明那个提升是过拟合评估集的产物。五折选出的权重极不稳定（(0.9,0.3,0.1)、(0.1,0,0)、(0.8,0.5,0)、(0.5,0.2,0)），进一步证明没有稳定的集成收益。

对比之下，双模型集成之所以有效（+0.93pp），是因为 ResNet18 与 MobileNetV3 能力接近（28.18% vs 25.82%），错误相关性低。一旦引入强得多的 Swin-T（34.93%），弱模型的信息就是噪声。

脚本：`ml/src/eval_ensemble.py`（评测 + 概率导出）、`ml/src/search_ensemble_weights.py`（权重搜索 + 留一折 CV）。

## 关键教训

跨域问题不能靠「改输入」解决。四条被证伪的路线有一个共同点：**都只改变了输入或输出的表层统计，没有改变模型内部依赖的特征类型**。要真正提升，必须让模型在训练时就被迫学习对成像条件不变的特征——即域泛化训练（背景替换、局部裁剪）或目标域微调。
