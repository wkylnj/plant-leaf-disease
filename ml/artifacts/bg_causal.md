# 背景的因果作用：注意力不等于因果依赖

> 一句话结论：**Grad-CAM 说「模型不看背景」（四角注意力 2.7%），但因果实验证明背景换掉就掉 16pp。**
> 把背景里的清晰叶片结构抹掉（模糊），掉幅从 16pp 缩到 2.7pp。
> 这说明模型依赖的是背景的**统计纹理**而非空间位置，注意力图看不到这种全局依赖。

## 1. 为什么要做这个

E-7 Grad-CAM 的结论是「模型不看背景，看整片叶子的全局统计特征」——依据是四角区域只占 2.7% 的注意力。

但这个结论有个方法论问题：**Grad-CAM 衡量的是梯度的空间流向，不是「把这块区域换掉模型会不会崩」**。注意力低 ≠ 不依赖。一个依赖全图颜色直方图的模型，其注意力可以均匀弥散在任何位置，但它对任何改变颜色分布的操作都极度敏感。

所以需要因果实验：**改输入、看输出**。

## 2. 实验设计

冻结 ResNet18（`runs/resnet18_224_15ep`，同域 99.41%），在 PlantVillage test 上抽 600 张，用 `foreground_mask()` 抠出叶片，把背景替换成不同类型，叶片像素一个不动：

| 变体 | 背景内容 | 想分离的因素 |
|---|---|---|
| `grey` | 原始灰紫背景（对照） | — |
| `solid_grey` | 纯灰 | 只改亮度 |
| `solid_green` | 纯绿 | 只改色相 |
| `noise` | 随机噪声 | 只有纹理、无颜色语义 |
| `blurred_bg` | 田间背景重度高斯模糊 | 保留田间颜色、抹掉清晰结构 |
| `field_bg` | 真实田间背景（清晰） | 颜色 + 纹理都变 |

关键对照是 `blurred_bg` vs `field_bg`：**同一批背景图，只差一个模糊**。

## 3. 结果（600 张）

| 背景类型 | 准确率 | 相对原始 |
|---|---|---|
| 原始灰紫背景 | **99.50%** | — |
| 纯灰 | 96.83% | −2.67pp |
| 纯绿 | 95.83% | −3.67pp |
| 田间背景**重度模糊** | **96.83%** | **−2.67pp** |
| 随机噪声 | 92.83% | −6.67pp |
| 田间背景（**清晰**） | **83.50%** | **−16.00pp** |

**决定性对比**：同一批田间背景图，模糊时只掉 2.67pp，清晰时掉 16.00pp。**6 倍的差距全部来自背景里的清晰结构。**

## 4. 三条结论

### 4.1 背景确实参与决策，而且影响很大

只换背景（叶片完全不动）就掉 16pp。E-7 的「模型不看背景」是注意力层面的观察，不能推成「背景无关」。

**这对报告是个好素材**：它展示了「可解释性方法给出的是相关性证据，因果结论必须靠干预实验」这个方法论要点。Grad-CAM 在这里不是错了，而是被误读了——它显示的是梯度流向，不是依赖强度。

### 4.2 模型依赖的是背景的「统计纹理」，不是空间位置

- 纯色背景（灰/绿）只掉 2.7~3.7pp → 单靠颜色统计影响有限
- 随机噪声掉 6.7pp → 纯纹理有影响但不大
- **清晰的田间背景掉 16pp** → 影响来自「看起来像叶片的纹理」

田间背景里全是其他绿叶。对模型来说，「画面里有健康绿叶纹理」是一个强信号，现在这个信号与贴上去的病叶标签冲突。

### 4.3 这与 E-2 手工特征实验互补

E-2 发现颜色直方图 102 维就有 79.41%（颜色主导同域判别）。本实验补充了另一面：**颜色只是同域判别的主力，跨到「背景有叶片纹理」的场景时，纹理结构的作用会盖过颜色**。

## 5. 对 FBR 的影响（重要限定）

FBR 合成图在已训练 PV 模型上只有 49.17%。为定位原因，做了两轮分解（`fbr_ablate.py`、`fbr_halo_test.py`）：

| 条件 | 准确率 |
|---|---|
| 原始 PV | 99.50% |
| 只换背景（清晰） | 83.50% |
| **完整合成（清晰背景）** | **49.17%** |
| 完整合成（背景模糊） | **85.83%** |
| 完整合成 + 掩膜腐蚀 2/3/5px | 45.33% / 45.17% / 44.83%（**更差**） |

两条推断：
- **「灰晕伪影」假设被否定**：bbox 内残留 32.6% 的 PV 灰底，但腐蚀掩膜切掉灰晕后准确率反而下降（因为腐蚀也切掉了病斑边缘）
- **「背景清晰结构」假设成立**：模糊背景后从 49.17% 恢复到 85.83%

**但这不直接证明 FBR 训练会失败**：上面的测试衡量的是「已训练好的 PV 模型在合成图上还能不能认」，而 FBR 的目的是训练一个**新模型**学会忽略背景。合成图对旧模型「难」，正是 FBR 想要的——难样本才能改变模型依赖的特征类型。

真正能判定的只有训练结果。**本诊断的价值是把 FBR 的成败条件说清楚了**：如果 FBR 训练出的模型在 PlantDoc 上提升，说明它学会了忽略背景叶片纹理；如果没提升，说明 38 类细粒度任务上「背景里的同类作物叶片」这个干扰太强，背景重组这条路不适用。

## 6. 已知局限

1. 只测了 ResNet18 一个模型（Swin-T 注意力机制不同，背景依赖可能更弱）
2. 每变体抽样 600 张，未做多种子与显著性检验
3. `foreground_mask()` 在真实田间背景上会锁到背景草叶而非目标叶片（本实验的替换背景是合成的，不受影响；但 `fbr_ablate` 的「背景涂灰」测试因此无效，已弃用该结果）
4. 模糊半径取 `size/12`（约 18px），只试了这一个强度
5. 未测「背景与叶片同类」vs「背景为其他作物」的差异
