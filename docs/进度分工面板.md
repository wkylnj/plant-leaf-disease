1. **找到自己那一节**（下面第 3 章），只看自己的任务。
2. **认领**：在任务行尾写 `@你的名字`，然后提交一次 commit。
3. **完成**：把 `- [ ]` 改成 `- [x]`，提交一次 commit。

**怎么改（重要）**：GitHub 仓库里的 Markdown 文件，复选框是**只读的**，直接点没反应。
正确做法：

1. 打开 https://github.com/wkylnj/plant-leaf-disease/blob/main/docs/进度分工面板.md
2. 点右上角 **铅笔图标**（Edit this file）
3. 把 `- [ ]` 改成 `- [x]`，滚到底点 **Commit changes**

## 6. 更新规则

### 6.1 每天

```bash
git checkout dev
git pull
# 改 docs/进度分工面板.md，勾选你做完的
git add docs/进度分工面板.md
git commit -m "chore: 完成 XXX 任务"
git push
```

### 6.2 每周例会

更新三处：
1. 第 4 章看板表
2. `docs/进度表.md`
3. `例会记录/YYYY-MM-DD-第N次.md`

### 6.3 状态约定

| 写法 | 含义 |
|---|---|
| `- [ ]` | 未开始或进行中 |
| `- [x]` | 已完成 |
| 行尾 `@名字` | 已认领 |
| 行尾 `（卡：原因）` | 卡住了，需要人帮 |

### 6.4 不要做的事

- 不要在没有认领的情况下改别人的任务
- 不要把没做完的勾上（报告里写"已完成"但代码不存在，一问就穿）
- 不要删别人的任务，只改状态
